CRITICAL DESIGN INSTRUCTIONS (READ BEFORE STARTING)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Avoid these traps (they're common but wrong for this brief):

⚠ NO "startup landing page" clichés: no gradient blob backgrounds, 
  no floating illustrations, no "As seen on" logos section, no big 
  stat blocks like "500+ clients".

⚠ NO tech vocabulary in French: don't use terms like "UX/UI", 
  "wireframes", "user flow", "sprint" — the target audience is a 
  lawyer, not a Product Manager.

⚠ NO fake social proof: no fake testimonials, no fake client logos, 
  no fake portfolio images. If a section requires real content that 
  doesn't exist yet, either skip it or use "Bientôt disponible" / 
  "Coming soon" placeholders.

⚠ NO icons everywhere: this is an editorial design, not a 
  dashboard. Use icons sparingly, only where they truly help 
  (e.g., LinkedIn icon in footer). Prefer typography over icons.

⚠ NO stock photography: if images are needed, prefer to leave 
  photo placeholders as terracotta-tinted blocks with the word 
  "Photo" written inside. Real photos will be added later.

Priority quality principles:
1. Typography quality — the mix of Cormorant serif and DM Sans sans 
   is the visual signature
2. Whitespace — never fill a section, always let it breathe
3. Restraint — every element must justify its presence
4. Editorial voice — write copy that sounds human, not marketing
